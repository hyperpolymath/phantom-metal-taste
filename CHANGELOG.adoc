= Changelog
:toc:

[IMPORTANT]
====
The former changelog asserted that a v0.1.0 release shipped an API,
databases, production-ready analytics, and a ReScript/Deno application. The
repository contains no matching release tag or GitHub release, and those
capabilities are not in the current source tree. Those unsupported claims have
been withdrawn rather than carried forward as project history. The current
source map is in `docs/architecture/ARCHITECTURE.adoc`.
====

== Unreleased remediation

=== Added

* Root Cargo workspace, Julia package, Bun site-builder tests, and deterministic
  allowlisted site publication.
* Rust, Julia, Bun, and Pages workflows with direct action commit pins and a
  pinned shared Rust reusable workflow.
* RSR provisioning engine integration, Just recipes, a generated launcher,
  mise declarations, and Guix development/source-package definitions.
* Setup, AI onboarding, implementation-status, and test-gap documentation.

=== Changed

* Rewrote the project and setup guides to describe only the implemented
  prototype and to distinguish conceptual diagrams/case study from code.
* Updated the GitLab mirror pipeline to exercise the current Rust/Julia/Bun
  code paths and publish the allowlisted site.
* Replaced unsupported certification/compliance claims with measured status.

=== Removed

* Retired the Deno/ReScript CI workflow and `deno.lock`; the remaining
  AffineScript files are explicitly documented as incomplete scaffolds.
* Removed the competing Pages workflow that uploaded the full repository.
* Retired the generic SLSA release workflow that generated and attested placeholder artifacts.

=== Verification still outstanding

* Generate and verify `mise.lock` with the official mise CLI.
* Generate and verify `.github/workflows/actions.lock` with `gh actions-lock`.
* Execute Rust and Julia tests and local provisioning validation; run
  actionlint/schema-aware workflow checks and remote CI in an environment with
  the required tools. YAML syntax and inline action-pin checks already pass.
* Confirm issue #77 acceptance on a fresh default-branch run before closing it.
