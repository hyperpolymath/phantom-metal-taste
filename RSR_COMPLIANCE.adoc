== Current evidence

* The repository follows the current estate language direction: Rust, Julia,
  and Bun toolchain declarations; no Deno or ReScript source/workflow remains.
* Root setup is provided by `Justfile`, `launcher.sh`, and the canonical
  provisioning module under `build/just/`.
* Guix files declare a pinned development shell and a source package.
* GitHub workflows include Rust CI, Julia tests, Bun/site checks, governance,
  security scanning, and a Pages builder restricted by `site.json`.
* `.well-known/security.txt`, `ai.txt`, and `humans.txt` are checked in and
  explicitly included in the published-site allowlist.
* `Cargo.lock` is tracked. `mise.lock` and `.github/workflows/actions.lock` are
  still outstanding generated artefacts; do not claim those lock gates pass.
* The AffineScript orchestrator remains unimplemented. There is no API,
  database integration, full integration suite, or measured coverage percentage.

== Open remediation gates

. Generate and review `mise.lock` with the official mise CLI on a machine that
  can reach mise's release metadata endpoints.
. Generate and verify `.github/workflows/actions.lock` with `gh actions-lock`
  v0.1.6; do not hand-maintain it.
. Run the Rust and Julia gates in an environment with those runtimes installed.
. Reconcile issue #77 only after fresh default-branch workflow evidence.
