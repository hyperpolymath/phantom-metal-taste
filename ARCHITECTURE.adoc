= Architecture and current implementation
:toc:

== Purpose

Phantom Metal Taste explores the gap between organisational intentions and
observed outcomes. It is currently a set of experimental libraries and research
artefacts, not a deployed application.

== Implemented components

[cols="1,2,3",options="header"]
|===
|Component |Location |Verified scope

|Rust core
|`Cargo.toml`, `src/core/`
|A `wasm-bindgen` library with unit tests. WASM output is optional and requires the wasm32 target.

|Julia analytics
|`Project.toml`, `src/PhantomAnalytics.jl`, `src/analytics/`, `test/`
|Prototype statistical and causal-analysis functions with a Julia package test suite.

|Static site tooling
|`package.json`, `scripts/build-site.mjs`, `site.json`
|Bun builds an allowlisted site artifact; CI checks reproducibility.

|AffineScript orchestration
|`src/orchestrator/*.affine`
|Scaffolds only; each file still requires semantic implementation and compiler verification.

|Database design
|`compose.yml`, diagrams, case study
|Conceptual/optional only. Current source does not connect to ArangoDB or Virtuoso.
|===

== Not implemented

There is no HTTP API, runtime server, case-study loader, graph persistence,
SPARQL integration, or end-to-end application flow. Database services are not
required to build, test, or run the Julia example. The TLA+ files and diagrams
are design artefacts; no current CI job claims that they have been model-checked
or generated from a running application.

== Local verification

Use `just build`, `just test`, `just lint`, `just fmt-check`, and `just
site-check`. The supported setup routes are in `docs/SETUP.adoc`; do not follow
historical Deno/ReScript instructions elsewhere in the repository.
