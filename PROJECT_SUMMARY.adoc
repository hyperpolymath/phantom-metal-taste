= Phantom Metal Taste — verified project summary
:toc:

== Status

This is an experimental repository, not a complete or production-ready
multi-model service. The conceptual design is broader than the code currently
implemented. In particular, there is no HTTP API, data loader, database client,
or end-to-end integration.

== Implemented source

* **Rust:** `src/core/` is a `wasm-bindgen` library in the root Cargo workspace;
  tests are embedded in the Rust crate.
* **Julia:** the root `Project.toml` packages the analyses in `src/analytics/`;
  `src/PhantomAnalytics.jl` exposes nested analysis modules and `test/` holds the
  Julia test suite.
* **Bun:** `scripts/build-site.mjs` builds the static allowlisted site described
  in `site.json`; its CLI helpers have Bun tests.
* **AffineScript:** `src/orchestrator/*.affine` remains TODO scaffolding.

== Build and test

```sh
./launcher.sh --setup
just build
just test
just site-check
just demo
```

The complete manual path is `docs/SETUP.adoc`. `compose.yml` is optional local
infrastructure and is not used by the current code. The diagrams, formal
specifications, and SynapCor case study are conceptual/design artefacts unless a
specific test or running implementation establishes otherwise.
