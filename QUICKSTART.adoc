== Phantom Metal Taste - Quickstart Guide

Get up and running in 5 minutes.

=== Prerequisites

Install these first: - https://deno.land[Deno] -
`+curl -fsSL https://deno.land/install.sh | sh+` -
https://podman.io[Podman] - `+sudo dnf install podman podman-compose+`

=== Installation

[source,bash]
----
# 1. Clone (or you already have it)
cd phantom-metal-taste

# 2. Build ReScript code
deno task build

# 3. Start databases (takes ~30 seconds)
podman-compose up -d

# 4. Wait for databases to be healthy
podman-compose ps
# Both should show "healthy" status

# 5. Start the API server
deno task dev
----

You should see:

....
✓ ArangoDB initialized
✓ Virtuoso initialized
✓ Server running at http://localhost:3000
....

==== API Endpoints

All endpoints return JSON:

[source,bash]
----
# Create an initiative
curl -X POST http://localhost:3000/api/initiatives \
  -H "Content-Type: application/json" \
  -d '{
    "name": "My Test Initiative",
    "description": "Testing the system",
    "startDate": "2024-01-01T00:00:00Z",
    "department": "Engineering",
    "intendedOutcome": "Learn the system",
    "status": "active",
    "participants": []
  }'

# Get gap analysis for an initiative (replace {id} with actual _key)
curl http://localhost:3000/api/analytics/gap/{id} | jq

# Find unintended consequences
curl http://localhost:3000/api/initiatives/{id}/unintended | jq
----

=== Philosophy

This system measures organizational delusion by: 1. Tracking stated
intentions 2. Recording actual outcomes 3. Calculating the gap 4.
Detecting when metrics are gamed 5. Identifying when metrics become
theater

The irony: A rigorous system to measure the limits of rigorous systems.

=== Troubleshooting

*Databases won’t start?*

[source,bash]
----
podman-compose down -v
podman-compose up -d
----

*API won’t connect to databases?* - Wait for "`healthy`" status:
`+podman-compose ps+` - Check logs: `+podman-compose logs arango+`

*Port 3000 already in use?* - Change in `+.env+`: `+PORT=3001+`

*Need help?* - See docs/SETUP.md for detailed troubleshooting
