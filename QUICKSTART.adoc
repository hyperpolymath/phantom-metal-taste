= Quick start
:toc:

This gets the *implemented pieces* of Phantom Metal Taste working locally. It
does not start an API or connect to the optional database containers: neither is
implemented in this checkout.

== 1. Install the prerequisites

Install Git and https://mise.jdx.dev/[mise] using your operating system's package
manager. If using Windows, run the steps inside WSL2.

== 2. Clone and provision

[source,bash]
----
git clone https://github.com/hyperpolymath/phantom-metal-taste.git
cd phantom-metal-taste
mise trust
./launcher.sh --setup
----

The launcher installs the declared tools with mise, fetches Rust and Julia
packages, and checks the environment. Alternatively, if `just` is already
installed, run `just setup`.

== 3. Build and test

[source,bash]
----
just build
just test
just site-check
----

The test command runs the Rust crate tests, Julia package tests, and Bun's
site-builder tests. The build command builds the Rust workspace, precompiles the
Julia package, and creates `_site/` from the allowlist in `site.json`.

== 4. Run the sample analysis

[source,bash]
----
just demo
----

This prints example intention/reality, metric-gaming, and causal-analysis
results. No server, API keys, external data, or containers are needed.

== Optional local databases

`compose.yml` is an infrastructure sketch, not an application dependency. To
run it, first export distinct, non-default local passwords:

[source,bash]
----
export ARANGO_ROOT_PASSWORD="$(openssl rand -base64 32)"
export VIRTUOSO_DBA_PASSWORD="$(openssl rand -base64 32)"
just db-up
----

Services bind to loopback only. The Rust/Julia code does not currently read or
write these databases. Stop them with `just db-down`.
