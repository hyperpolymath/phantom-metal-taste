[[binding-rules]]
== Binding estate rules

The source-of-truth order is current `hyperpolymath/standards`, current
`hyperpolymath/rsr-template-repo` for canonical instantiation, verified local
source/state, then legacy prose. In particular:

. The current estate language policy makes AffineScript the direction for future application behavior, Bun the tier-1 JavaScript runtime, and prohibits Deno. ReScript/TypeScript legacy work is not a reason to restore either old runtime path.
. The current template reusable pin recorded during recon is `da2c748aad55c1a1dcba00b60fe4a35017bc6540`; keep reusable workflow callers on full reachable SHAs.
. Workflow SPDX validation must accept an SPDX line in the leading comment block, including when a lock tool adds its own comment above it.
. Generate `.github/workflows/actions.lock` using the official `gh-actions-lock` tool. Do not hand-write lock data or guess action resolutions. Keep direct action refs immutable; validate the lock after generation.
. Generate `mise.lock` using official mise tooling. Do not write checksums or release metadata by hand. The current `mise.lock` gap is a release/setup reproducibility blocker.
. Provisioning engine code in `build/just/` is canonical estate code. Put provisioning facts in `.machine_readable/descriptiles/provisioning_praxis.deed`, repo-wide facts in `phantom-metal-taste_chora.deed`, and project tasks in the root `Justfile`.
. The current RSR template retires A2ML. Keep all `.a2ml` files removed; the old descriptive A2ML records and non-executable A2ML contractile declarations are not authoritative. Adopt applicable contractiles in the current `.k9.ncl`/Nickel format rather than reviving the old files.
. Apply the current template capability-by-capability. Do not copy unrelated languages, FFI, services, containers, or formal-method scaffolding simply to imitate the template.

Binding references: link:https://github.com/hyperpolymath/standards/blob/main/3-practice/provisioning/PROVISIONING-STANDARD.adoc[Provisioning Standard], link:https://github.com/hyperpolymath/standards/issues/727[standards#727], link:https://github.com/hyperpolymath/standards/issues/1108[standards#1108], the link:https://github.com/hyperpolymath/rsr-template-repo[RSR template], and the pinned reusable workflow commit above.
