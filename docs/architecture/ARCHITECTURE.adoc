= Current architecture and implementation status
:toc:

[IMPORTANT]
====
This page records what is present in the repository today. Older diagrams and
enterprise design documents are conceptual proposals; they do not describe a
running service.
====

== Current source map

* `Cargo.toml` is a Rust workspace containing `src/core/`, a small
  `wasm-bindgen` library with tests.
* `Project.toml` defines the Julia package. `src/PhantomAnalytics.jl` loads the
  analysis prototypes under `src/analytics/`; `test/runtests.jl` exercises the
  exposed functions.
* `package.json` declares Bun scripts for the static site builder and its tests.
  `site.json` is the publish allowlist; `scripts/build-site.mjs` builds the
  output without a server framework or third-party JS dependencies.
* `src/orchestrator/` contains five AffineScript TODO scaffolds. They are not
  compiled or semantically complete.

== Boundaries

No HTTP API, orchestration runtime, data loader, ArangoDB client, Virtuoso
integration, or persistent application service exists. `compose.yml` can start
optional local database containers, but no current code consumes them. The
SynapCor story, diagrams, and TLA+ files communicate design intent only.

== Build and test

`just build` delegates to Rust, Julia, and Bun defaults. `just test` runs the
Rust and Julia suites plus Bun tests. `just site-check` rebuilds the site twice
and compares the complete outputs. `just run` reports N/A; there is no runnable
application entry point.

The semantic AffineScript migration is separate work. Before implementing it,
define intended behavior and tests, verify the supported compiler, and retain
the distinction between new implementation and legacy scaffolding.
