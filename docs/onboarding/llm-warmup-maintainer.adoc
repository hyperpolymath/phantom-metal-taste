= LLM warm-up — Phantom Metal Taste (maintainer)

Read `llm-warmup-dev.adoc` first. This adds the repository maintenance facts.

== Provisioning ownership

The current estate engine is in `build/just/provision.just`,
`build/just/provision-lib.sh`, and `build/just/provision-modes.sh`. Treat those as
canonical vendored code; project-specific facts belong in
`.machine_readable/descriptiles/provisioning_praxis.deed`. Keep root `Justfile`,
Guix files, README, setup docs, and this guide accurate as the project changes.
The launcher is generated from the standards template. `Cargo.lock` is Cargo
output; `mise.lock` must be generated by `mise lock`; never fabricate either
lock. Julia's `Manifest.toml` is ignored by project policy.

== Current blockers and status

* `mise.lock` is absent because the sandbox could not reach the required Julia
  version metadata host. Generate and review it in an egress-enabled environment.
* `gh actions-lock` v0.1.6 could not be installed here because its release binary
  is served from a host outside the workspace's network allowlist. The workflow
  refs are currently full SHAs, but `.github/workflows/actions.lock` still needs
  to be generated and verified with the official tool.
* Rust and Julia executables were unavailable locally, so their CI/package tests
  have not been replayed in this environment.
* The AffineScript orchestrator is still five TODO scaffolds; do not claim the
  semantic migration or service is complete.

== Maintainer loop

. Run `just toolchain-refresh` where mise and Guix metadata are reachable.
. Run `gh actions-lock` and `gh actions-lock --no-fix`, then inspect workflow
  changes and leading SPDX comment blocks.
. Run `just doctor`, `just validate`, and all workflow checks before requesting
  review. If a runtime is unavailable, name the missing gate rather than
  recording a pass.
. Keep issue #77 open until a fresh default-branch run meets its acceptance.
