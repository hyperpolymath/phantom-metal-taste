== Limits and follow-up

* Rust WASM target compilation is optional and has not been replayed locally in
  this environment; use `just wasm-build` where rustup and the target are available.
* Julia tests were added with the root package setup but could not be executed in
  the current sandbox because Julia is not installed. CI is the first runtime
  execution gate; do not report the suite as locally passed until run.
* The analytics tests are smoke/contract tests, not statistical validation or
  coverage evidence. Numerical edge cases, missing data, collinearity, and
  decision thresholds need domain review.
* The AffineScript semantic port needs a separate behavior specification, a
  supported compiler/toolchain, and tests before any TODO scaffold is treated
  as implemented.
* Database integration tests require actual clients, schemas, fixtures, and
  explicit security decisions; merely starting containers is not coverage.
