= Governance
:toc:

== Status

This is a single-maintainer experimental repository. The default code owner is
link:https://github.com/hyperpolymath[@hyperpolymath] in `.github/CODEOWNERS`.
GitHub repository permissions and configured branch protections are authoritative
for access, review, and merging; this document does not invent a multi-person
council or unconfigured approval threshold.

== Contributions and decisions

Contributors should open an issue or pull request for substantive changes,
include evidence and tests, and update relevant user-facing documentation.
The maintainer reviews changes and decides scope. Significant architecture or
policy changes should be discussed before implementation. Do not represent
conceptual case-study material as a live system capability.

Follow `.github/CONTRIBUTING.md`, `CODE_OF_CONDUCT.adoc`, and the binding
`hyperpolymath/standards` and `hyperpolymath/rsr-template-repo` policies.

== Security and conduct

Report vulnerabilities through GitHub Security Advisories; details are in
`SECURITY.adoc`. Conduct concerns should be reported privately through a
maintainer-controlled channel. Do not publish private data or credentials.
