= Security policy
:toc:

== Reporting vulnerabilities

Please report suspected vulnerabilities privately through GitHub's Security
Advisories for this repository. Do not post exploit details, credentials, or
private data in public issues. Include a concise impact description and a
reproduction that does not expose real user information.

== Current security boundary

This repository currently ships an experimental Rust library, Julia analysis
prototypes, and a Bun static-site builder. It does not ship an HTTP API or
production service. The optional ArangoDB/Virtuoso compose setup is local-only,
requires user-supplied non-default passwords, and binds published ports to
loopback. The current application code does not connect to those containers.

Do not infer API authentication, rate limiting, access controls, database
security, or runtime sandboxing from old architecture documents. Those controls
are not implemented because the corresponding service is not implemented.

== Dependencies and secrets

* Keep Cargo dependencies locked in `Cargo.lock`; use mise's generated lock only
  after creating it with the official CLI.
* Workflow actions must be immutable commit pins or covered by a generated,
  verified `.github/workflows/actions.lock`.
* Never commit `.env`, passwords, private keys, tokens, or production data.
* Keep the Bun site publisher restricted to the reviewed allowlist in `site.json`.

== Supported tools

Use the toolchain and setup steps in `mise.toml` and `docs/SETUP.adoc`. New
runtime/build paths must follow current
https://github.com/hyperpolymath/standards[estate policy].
