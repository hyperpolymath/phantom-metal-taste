= Phantom Metal Taste: project status

Phantom Metal Taste is an experimental project about measuring the distance
between organisational intentions and observed outcomes. The source currently
contains a small Rust library, Julia analytics prototypes, and a Bun-powered
static site builder.

There is no HTTP API, server, data loader, or application/database integration.
The `.affine` orchestrator files are TODO scaffolds. Diagrams and the SynapCor
case study are conceptual material, not evidence of running capabilities.

For a tested starting point, see link:QUICKSTART.adoc[QUICKSTART.adoc],
link:docs/SETUP.adoc[docs/SETUP.adoc], and
link:docs/architecture/ARCHITECTURE.adoc[the current implementation map].
